# AECBot — règles documentaires

- Le programme général est une référence **provisoire** : vérifier l'édition et l'éventuelle publication d'une version plus récente.
- Distinguer programme général, livrets, plans, publications 2026 et archives.
- La date `modified` est la date WordPress, **pas** une preuve de date de rédaction ni d'adoption.
- Citer le titre, l'URL source et la page PDF (repère `## Page N`).
- Ne jamais inventer une mesure ou une citation. Signaler les contradictions entre éditions.
- Les archives du NFP sont exclues par défaut : utiliser `--include-archives` pour les ajouter.
- Les dossiers de presse et documents non classés sont exclus par défaut.
- La classification par nom de fichier est indicative : réviser `gpt_manifest.json` avant diffusion.
